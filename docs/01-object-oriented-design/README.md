# Module 1 - Object-Oriented Design

## Overview
This module explores object opriented design concept. It emphasize on design thought & principles instead of learning language feature's syntax. The main agenda is to understand the problem, reasoning and design decision for which the OOP itself invented. Instead of answare how, the module should answer first why ? By the end of the module reader will natarually adopt OOP core concepts, build strong fundamental to convert a bussiness thought into Object Oriented Design, know adventages of OOP and make decision when to use it.

## Why This Module Exists
Almost every problems solution exist in procedural programming. But software's will sustained and be matured based on maintainability, testability, scalability and so on. Here is the limitations of procedural programming that addressed much more in OOP. Object Oriented Design thoughts and principles reduced limitations, maintain costs and increased adaptability to future requirements.

## Learning Objectives
- Adopt OOP core concepts.
- Knowing why OOP invented & face problems raised before OOP.
- Build Strong fundamental of OOD.
- Try to solve problems raised before and then practically use OOP to solve that problems.
- Learn to give a shape of business thought into a Object Oriented Design.
- Learn software engineering standards & priciples, practices OOD that globally acceptable.

## Prerequisites
To continue with this module anyone who is interested need to know atleast:
  - Strong knowlege of programming fundamentals
  - Basic OOP concepts
  - Python programming
