# Documentation

This directory contains the theoretical part of the Software Architecture Masterclass.

Each module documents the concepts before implementing them in code.

The objective is to understand **why** a particular design or pattern exists rather than simply learning **how** to implement it.

## Contents

Each module may include:

- Overview
- Problem Statement
- Naive Solution
- Why It Fails
- Better Solution
- Pattern Explanation
- Diagrams
- Frequently Asked Questions
- References
- Key Takeaways

The documentation is intended to be read alongside the corresponding examples located in the `examples/` directory.
