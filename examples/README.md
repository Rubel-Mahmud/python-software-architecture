# Examples

This directory contains executable Python examples for every topic covered in the course.

The examples are intentionally implemented using pure Python before introducing frameworks such as Django or FastAPI.

The goal is to understand software design independently of any framework.

## Structure

Each module contains multiple progressively improved implementations.

Typical progression:

1. Naive implementation
2. Problem demonstration
3. Refactored implementation
4. Final architecture

Every example should be executable and easy to understand.
