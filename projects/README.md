# Projects

This directory contains practical projects developed throughout the course.

Projects are divided into two categories.

## Mini Projects

Small projects focused on applying a specific concept or pattern.

Examples:

- Bank Account
- Inventory Management
- Library System
- Task Manager

## Final Project

A production-quality application that combines everything learned during the course.

The final project will demonstrate:

- Object-Oriented Design
- SOLID Principles
- Clean Architecture
- Dependency Injection
- Repository Pattern
- Domain-Driven Design
- Testing
- Modern Engineering Practices

The objective is to create a project suitable for a professional GitHub portfolio.
